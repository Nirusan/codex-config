# Editorial web design

Use this direction for an intentionally expressive website. Existing product design and the requested scope take precedence.

Choose hierarchy, typography, imagery and density from the actual content. Useful compositions include a cinematic center, asymmetric hero, editorial split, or a small interlocking grid. Do not force a sales funnel onto a dashboard or application screen. Use authentic assets and real copy; label synthetic fixtures when prototyping.

Keep headings legible at target widths and text zoom; adjust width and type scale rather than imposing a universal line count. Check CTA contrast, alignment across cards, meaningful whitespace, keyboard order and overflow. Dense grids must preserve logical reading and focus order.

Motion can establish hierarchy or explain an interaction. Use existing animation tools; add GSAP only when the requested effect needs it. Pinning, scrubbing, text reveals and card stacking are options, not a bundle. Provide reduced-motion behavior and readable content without animation. Clean up scroll listeners and timelines on navigation.

Select layouts deliberately. Never simulate tool execution or fabricate RNG results. Inspect the rendered result at relevant desktop and mobile widths; fix actual clipping and contrast issues rather than masking them with global overflow hiding.
