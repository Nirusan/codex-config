# Extracting a complex visual reference

- Record a small set of reusable layout, spacing, typography and color tokens. Estimate uncertain values, then refine against the rendered result.
- Separate artwork from actual controls and text. Reproduce imagery as assets; implement content, buttons and navigation accessibly.
- Check crop, aspect ratio and focal point for each image role. Preserve provenance and obtain an appropriate asset when a tiny reference cannot support the required size.
- Let real content determine section height. Keep one clear first-screen hierarchy; avoid nested ornamental panels that add no meaning.
- Judge line breaks and visual rhythm at the target viewport, then adapt intentionally for mobile and text zoom. A desktop mockup does not define mobile behavior.
- Compare the important regions directly: content edges, heading baseline, image proportions, gaps and CTA placement. Iterate on observed differences; do not declare fidelity from code inspection alone.
