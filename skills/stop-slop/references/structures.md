# Structures to Avoid

## Binary Contrasts

These create false drama. State the point directly.

Especially avoid slogan-style binary contrast patterns like:
- `not X, just Y`
- `this isn't X, it's Y`
- `not a tool, a teammate`
- `not search, research`
- `not a new tier, just an upsell funnel`

These usually sound templated, overcompressed, and AI-written unless the writer has a very specific voice carrying the line.

Default fix: replace the contrast with the actual point.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliche |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula, different words |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |

**Instead:** State Y directly. "The problem is Y." "Y matters here." Drop the negation entirely.

## Negative Listing

Listing what something is *not* before revealing what it *is*. A rhetorical striptease.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |

**Instead:** State Z. The reader doesn't need the runway.

## Dramatic Fragmentation

Sentence fragments for emphasis read as manufactured profundity.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

**Instead:** Complete sentences. Trust content over presentation.

## Tagline Fragments

Short contrast tags and mini-slogans often show up in intros, subheads, endings, and CTA-adjacent copy. They look punchy, but they usually carry less information than a plain sentence.

| Pattern | Problem |
|---------|---------|
| "Tradeoffs, not hype." | Marketing contrast disguised as clarity |
| "Signals, not noise." | Generic anti-buzzword slogan |
| "Action, not theory." | Empty promise unless you say what action |
| "Speed, not ceremony." | Brand voice shortcut with no payload |
| "X, not Y." as a standalone sentence | Mechanical contrast tag |

These lines are usually too short to earn their tone. They feel written to sound sharp, not to say something.

**Instead:** write the actual sentence.

- "This comparison focuses on practical tradeoffs."
- "The guide explains what you get, what you give up, and where each tool fits."
- "Choose based on channel needs, learning model, and operating cost."

## Blog Intro and Subhead Slop

These patterns show up in blog intros, comparison posts, LinkedIn essays, and landing-page sections. The sentence sounds polished, but it delays the point or brands the paragraph instead of informing the reader.

| Pattern | Problem |
|---------|---------|
| "If you're choosing X, this is the breakdown you need." | Framing the utility instead of giving it |
| "The real question is..." | Writerly setup before the claim |
| "This is where X gets interesting." | Teaser sentence with no payload |
| "This is not about X. It's about Y." | Mechanical reframe |
| "What X gets right" / "Where X shines" as a subhead | Review-template phrasing |
| "X wins by a wide margin" as a subhead | Verdict language before evidence |
| "The honest truth" / "honest comparison" inside body copy | Trust-signaling instead of substance |
| "Here is the breakdown" / "here's what matters" | Presentation talk, not content |
| "This part is not close." | Empty scene-setting sentence |
| "The core idea is simple:" | Stage direction before the idea |

These lines are often one edit away from sounding normal. The problem is not the topic. The problem is the setup.

**Instead:**
- lead with the actual claim
- name the concrete distinction
- turn subheads into information, not verdicts
- delete the scene-setting sentence if the next sentence already does the job

Examples:
- Instead of "The real question is what job you need the agent to do," write "Choose based on the job you need the agent to do."
- Instead of "This is where Hermes Agent has the clearest edge," start with the edge itself.
- Instead of "OpenClaw wins by a wide margin," write the scope: "OpenClaw supports 22+ channels. Hermes Agent supports 6."

## Rhetorical Setups

These announce insight rather than deliver it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |

**Instead:** Make the point. Let readers draw conclusions.

## Formulaic Constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |

## False Agency

Giving inanimate things human verbs. Complaints don't "become" fixes. Bets don't "live or die." Decisions don't "emerge." A person does something to make those things happen. AI loves this because it avoids naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "a bet lives or dies in days" | Bets don't have lifespans. Someone kills the project or ships it. |
| "the decision emerges" | Decisions don't emerge. Someone decides. |
| "the culture shifts" | Cultures don't shift on their own. People change behavior. |
| "the conversation moves toward" | Conversations don't move. Someone steers. |
| "the data tells us" | Data sits there. Someone reads it and draws a conclusion. |
| "the market rewards" | Markets don't reward. Buyers pay for things. |

**Instead:** Name the human. "The team fixed it that week" beats "the complaint becomes a fix." If no specific person fits, use "you" to put the reader in the seat.

## Narrator-from-a-Distance

Floating above the scene instead of putting the reader in it.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | Same |
| "People tend to..." | Armchair sociologist |

**Instead:** Put the reader in the room. "You don't sit down one day and decide to..." beats "Nobody designed this."

## Reddit AI Slop Pattern ("Discovery Post")

The slow-reveal structure where the author pretends to stumble onto an insight. Extremely common on r/openclaw, r/AI_Agents, r/ClaudeAI.

| Pattern | Problem |
|---------|--------|
| "I've been lurking/experimenting" opener | Fake humble setup |
| One sentence per paragraph | LinkedIn drama formatting on Reddit |
| "That's where things got interesting" | Manufactured suspense |
| Bold text for the "big reveal" | False profundity |
| Numbered list of "unexpected" findings | Staged discovery |
| Closing rhetorical question ("what workflow would you automate?") | Engagement bait |
| "And honestly... I never found that compelling" | Performed skepticism before the pivot |

**Instead:** State the setup in 2-3 sentences. Get to the point. Share the actual config/numbers/commands. Skip the narrative arc. Reddit rewards specifics, not storytelling.

## Outline Filler

These are school-essay endings disguised as insight.

| Pattern | Problem |
|---------|---------|
| "Despite its success, it faces several challenges" | Generic late-paragraph turn |
| "Despite these challenges" | Boilerplate recovery sentence |
| "Future outlook" / "Future prospects" | Empty forecast frame |
| "Challenges and opportunities" | Consultant mush |
| "continues to evolve" | Says nothing |

**Instead:** Name the actual problem, the actual constraint, or the actual next step.

## Inflated Verb Swaps

AI often rewrites plain sentences into heavier ones for no gain.

| Pattern | Problem |
|---------|---------|
| "serves as" instead of "is" | Unnecessary inflation |
| "boasts" / "features" / "offers" instead of "has" | Sales language |
| "holds the distinction of" | Prestige padding |
| "represents" / "marks" where a plain verb works | Grandiose framing |

**Instead:** Prefer is, are, has, uses, includes, became, did.

## Passive Voice

Every sentence needs a subject doing something. Passive voice hides the actor and drains energy.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

**Instead:** Find the actor. Put them at the front of the sentence.

## Sentence Starters to Avoid

| Pattern | Fix |
|---------|-----|
| Sentences starting with What, When, Where, Which, Who, Why, How | Restructure. Lead with the subject or the verb. |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

Wh- openers become a crutch. "What makes this hard is..." becomes "The constraint is..." or better, name the specific constraint.

## Rhythm Patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists | Use two items or one |
| Questions answered immediately | Let questions breathe or cut them |
| Every paragraph ends punchily | Vary endings |
| Em-dashes | Remove. Use commas or periods. No em dashes at all. |
| Staccato fragmentation | Don't stack short punchy sentences |
| "Not always. Not perfectly." | Hedging disguised as reassurance |

## Word Patterns

| Pattern | Problem |
|---------|---------|
| Lazy extremes (every, always, never, everyone, everybody, nobody) | False authority. Use specifics instead of sweeping claims. |
| All adverbs (-ly words, "really," "just," "literally," "genuinely," "honestly," "simply," "actually") | Empty emphasis. See phrases.md for full list. |
